# Wallpaper Backgrounds

This folder contains background images for the wallpaper builder feature.

## Required Images

Please add the following background images to this folder:

1. **cosmic.jpg** - A cosmic/space themed background with stars and nebulas
2. **desert.jpg** - A desert landscape background
3. **playa.jpg** - Black Rock City playa background
4. **stars.jpg** - Night sky with stars
5. **abstract.jpg** - Abstract artistic background

## Image Specifications

- **Resolution**: At least 1290x2796px (iPhone 15 Pro dimensions)
- **Format**: JPEG or PNG
- **File size**: Try to keep under 500KB for web performance
- **Orientation**: Portrait (vertical)

## Thumbnail Images (Optional)

For better performance, you can also add thumbnail versions:
- **cosmic-thumb.jpg** (200x400px)
- **desert-thumb.jpg** (200x400px)
- **playa-thumb.jpg** (200x400px)
- **stars-thumb.jpg** (200x400px)
- **abstract-thumb.jpg** (200x400px)

## Default Fallback

If no backgrounds are provided, the wallpaper builder will still work with:
- Solid color backgrounds
- User-uploaded images
